# تطبيق شمالنا خضراء - Flutter Mobile App

## 📱 نظرة عامة

تطبيق Flutter متكامل للتعرف على النباتات البرية في مدينة عرعر، المملكة العربية السعودية. التطبيق يدعم RTL بالكامل ويعرض خريطة تفاعلية مع دبابيس للمواقع المجتمعية.

## 🎯 الميزات الرئيسية

### 1. نظام RTL الكامل
- **جميع الشاشات**: RTL بدون استثناء
- **جميع حقول الإدخال**: البريد الإلكتروني، كلمة المرور، التعليقات - كلها RTL
- **التطبيق بالكامل**: من `main.dart` يتم تفعيل RTL على مستوى التطبيق

### 2. نظام الشعارين
- **Logo.jpeg**: الشعار الرئيسي (يعرض بالحجم الكامل - `BoxFit.contain`)
- **Logo2.jpeg**: شعار الجمعية
- **الموقع**: يعرضان جنباً إلى جنب في:
  - شاشة الافتتاح (`splash_screen.dart`)
  - شاشة تسجيل الدخول (`login_screen.dart`)
  - الشاشة الرئيسية (`home_screen.dart`)
  - شاشة معلومات الجمعية (`association_info_screen.dart`)

### 3. نظام الخريطة التفاعلية
- **المكتبة**: `flutter_map` مع OpenStreetMap
- **المنطقة**: مدينة عرعر فقط (30.9753, 41.0381)
- **الدبابيس**: دوائر مع صور النباتات المنشورة
- **التفاعل**: الضغط على أي دبوس يعرض:
  - صورة النبات
  - التعليق
  - اسم الناشر
  - اسم النبات
  - زر للانتقال لصفحة التفاصيل

### 4. نظام النشر للمجتمع
- **من شاشة الكاميرا**: بعد التعرف على النبات
- **الخطوات**:
  1. التقاط صورة
  2. التعرف التلقائي بالذكاء الاصطناعي
  3. إضافة تعليق (اختياري)
  4. النشر على الخريطة
- **النتيجة**: يظهر فوراً على الخريطة كدبوس دائري مع الصورة

### 5. عرض صور حقيقية للنباتات
- **المصدر**: صور من مجلدات التدريب (`backend/ml/data/train/`)
- **في الشاشة الرئيسية**: كل نبات يعرض صورته الحقيقية
- **في الخريطة**: الدبابيس تعرض صور النباتات المنشورة
- **API**: `/api/plants/:id/image` يعيد صورة النبات من training data

## 🚀 التشغيل

### المتطلبات
- Flutter SDK 3.0+
- Dart 3.0+
- Android Studio / VS Code
- Backend يعمل على `http://localhost:3000`
- ML Service يعمل على `http://localhost:5000`

### خطوات التشغيل

```bash
# 1. الانتقال لمجلد التطبيق
cd mobile_app

# 2. تثبيت الاعتماديات
flutter pub get

# 3. التأكد من وجود الشعارين
# Logo.jpeg و Logo2.jpeg في assets/images/

# 4. تشغيل التطبيق
flutter run
```

### للجهاز الحقيقي

في `lib/services/api_service.dart`، غيّر:
```dart
final String baseUrl = 'http://YOUR_IP:3000';
```

## 📝 ملاحظات مهمة

### RTL
- **جميع الشاشات**: تستخدم `Directionality` مع `TextDirection.rtl`
- **جميع حقول الإدخال**: `textDirection: TextDirection.rtl`
- **لا استثناءات**: حتى البريد الإلكتروني وكلمة المرور RTL

### الشعاران
- **الحجم الكامل**: الشعار الأول يعرض بـ `BoxFit.contain` (بدون قص)
- **الموقع**: جنباً إلى جنب في جميع الشاشات المذكورة
- **الأحجام**:
  - Splash: 120x120
  - Login: 100x100
  - Home: 80x80
  - Association Info: 110x110

### الخريطة
- **المكتبة**: `flutter_map` (بدلاً من `google_maps_flutter`)
- **الخريطة**: OpenStreetMap (مجاني)
- **المنطقة**: عرعر فقط (حدود محددة)
- **الدبابيس**: دوائر 80x80 مع صور النباتات

### الصور
- **في Home**: صور حقيقية من `/api/plants/:id/image`
- **في الخريطة**: صور من `/uploads/` للمواقع المنشورة
- **في Training**: صور من `backend/ml/data/train/`

## 🔧 التخصيص

### تغيير عنوان API

في `lib/services/api_service.dart`:
```dart
final String baseUrl = 'http://YOUR_IP:3000';
```

### إضافة نباتات جديدة

1. أضف النبات في `backend/plants_data.json`
2. أضف صور في `backend/ml/data/train/اسم_النبات/`
3. أعد تدريب النموذج
4. التطبيق سيستخدم البيانات الجديدة تلقائياً
