# 🌱 نظام التعرف على النباتات بالذكاء الاصطناعي

## 📋 المتطلبات

قبل البدء، تأكد من تثبيت Python 3.8 أو أحدث.

## 🚀 الإعداد والتشغيل

### 1. تثبيت المكتبات

```bash
cd backend/ml
pip install -r requirements.txt
```

### 2. إعداد بيانات التدريب

```bash
python setup_data.py
```

هذا سينشئ المجلدات المطلوبة تلقائياً بناءً على النباتات الموجودة في `plants_data.json`:

```
data/train/
├── الجراز/
├── القصيص (الرقروق, الإرقة، الإجرد، الهشمة)/
├── البسباس/
├── الشقارى/
├── الصفار/
├── الفقاحسيلين العربية (ابودهينة)/
├── النقد/
├── الحزاء أو الحزز/
├── الخردل البري/
└── القرطية/
... وغيرها من النباتات في JSON
```

### 3. جمع الصور للتدريب

ضع صور كل نبات في المجلد المناسب حسب الاسم الموجود في `plants_data.json`:
- كل نبات له مجلد باسمه الشائع الرئيسي
- مثال: `data/train/الجراز/`، `data/train/البسباس/`، إلخ

**ملاحظات مهمة:**
- تحتاج **50-100 صورة على الأقل** لكل نبات لنتائج جيدة
- استخدم صور متنوعة من زوايا مختلفة
- صور في ظروف إضاءة مختلفة
- صور من مواسم مختلفة إن أمكن

### 4. تدريب النموذج

```bash
python train_model.py
```

سيتم:
- تحميل الصور ومعالجتها
- تدريب النموذج
- حفظ النموذج في `models/plant_recognition_model.h5`
- حفظ فئات النباتات في `models/plant_classes.json`

**مدة التدريب:** قد تستغرق 30-60 دقيقة حسب حجم البيانات ومواصفات الجهاز.

### 5. تشغيل خدمة API

```bash
python app.py
```

الخدمة ستعمل على المنفذ **5000** افتراضياً.

### 6. ربط Node.js بخدمة ML

تأكد من أن متغير البيئة `ML_SERVICE_URL` يشير للخدمة:
```bash
export ML_SERVICE_URL=http://localhost:5000
```

أو في Windows:
```cmd
set ML_SERVICE_URL=http://localhost:5000
```

## 🧪 اختبار النظام

### اختبار خدمة ML مباشرة:

```bash
curl -X POST http://localhost:5000/recognize \
  -F "image=@path/to/plant_image.jpg"
```

### اختبار من Node.js:

```bash
curl -X POST http://localhost:3000/api/plants/recognize \
  -F "image=@path/to/plant_image.jpg"
```

## 🔧 تحسين النموذج

### إضافة نباتات جديدة:

1. أضف بيانات النبات في ملف `plants_data.json` في المجلد `backend/`
2. شغّل `setup_data.py` لإنشاء المجلد الجديد تلقائياً
3. ضع صور النبات في المجلد المناسب
4. شغّل `train_model.py` من جديد

### تحسين الدقة:

- زود عدد الصور لكل نبات (100+ صورة)
- استخدم صور بجودة أعلى
- زود عدد epochs في `train_model.py`
- استخدم augmentation إضافي

## ⚠️ استكشاف الأخطاء

### الخطأ: "النموذج غير محمل"
- تأكد من تشغيل `train_model.py` أولاً
- تحقق من وجود `models/plant_recognition_model.h5`

### الخطأ: "خدمة التعرف غير متاحة"
- تأكد من تشغيل `python app.py`
- تحقق من المنفذ 5000
- تأكد من متغير `ML_SERVICE_URL` في Node.js

### دقة منخفضة:
- زود عدد صور التدريب
- استخدم صور أكثر تنوعاً
- أعد التدريب بعد إضافة المزيد من البيانات

## 📝 ملاحظات

- النموذج يستخدم **MobileNetV2** كـ base model
- حجم الصورة المدخل: **224x224**
- يدعم **Top-3 predictions**
- يعمل التعرف في الوقت الفعلي
